Sensor setup

Oil pressure and knock retard are not on the standard OBD-II list for most cars. They need a manufacturer-specific code, usually a mode 22 request like 221234. Enter the code for your car, the formula that turns the reply bytes (A, B, C, D) into a number, and the units that number is in. Oil temperature and charge air temperature start with the standard codes, which some cars do not answer.
